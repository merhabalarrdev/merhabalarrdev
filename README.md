### 🇹🇷 Hakkımda

CS 1.6 ile uzun yıllardır uğraşıyorum. Uzun süre sunucularda oynadım, zamanla plugin yazmaya merak sardım. Pawn dilini, değerli bir abim diyebileceğim birinden öğrendim — hâlâ öğrenme sürecindeyim. Şu sıralar diğer yazılım dillerine de el atmaya başladım.

Yaptığım pluginler genelde Zombie Plague / Zombie Escape modlarına yönelik — banka sistemi, pet sistemi, ışık ayarları gibi şeyler. Bunların yanı sıra CS 1.6 için özel bir **Valorant modu** geliştirdim; özel skill sistemi, yetenekler, kill mark sistemleri ve daha fazlasını içeriyor. Mod şu an aktif bir sunucuda oynanıyor — sunucuya özel olduğu için herkese açık değil. Türkçe, İngilizce ve Korece dil desteği eklemeye özen gösteriyorum.

---

### 🌍 About Me

I've been into CS 1.6 for many years. Spent a long time playing on servers, then slowly got into plugin development. I learned Pawn from someone I'd call a mentor — still learning to this day. Lately I've been picking up other programming languages as well.

Most of my plugins are for Zombie Plague / Zombie Escape servers. I also developed a custom **Valorant mod** for CS 1.6 — featuring a unique skill system, agent abilities, kill mark mechanics and more. It's currently running on a live server but kept private. I put effort into multi-language support (TR / EN / KO).

### 🇰🇷 소개

오랜 시간 CS 1.6을 플레이해 왔습니다. 오랫동안 서버에서 게임을 즐기다가 자연스럽게 플러그인 개발에 관심을 갖게 되었습니다. Pawn 언어는 존경하는 분께 배웠으며, 지금도 계속 배우는 중입니다. 요즘은 다른 프로그래밍 언어도 공부하기 시작했습니다.

주로 Zombie Plague / Zombie Escape 서버용 플러그인을 만들고 있습니다. 또한 CS 1.6용 **발로란트 모드**를 직접 개발했습니다 — 고유한 스킬 시스템, 요원 능력, 킬 마크 시스템 등이 포함되어 있습니다. 현재 활성 서버에서 운영 중이며, 서버 전용이라 공개되지 않습니다. 터키어, 영어, 한국어 다국어 지원을 항상 신경 씁니다.
