### 🇹🇷 Hakkımda

CS 1.6 ile uzun yıllardır uğraşıyorum. Uzun süre sunucularda oynadım, zamanla plugin yazmaya merak sardım. Pawn dilini, değerli bir abim diyebileceğim birinden öğrendim — hâlâ öğrenme sürecindeyim. Şu sıralar diğer yazılım dillerine de el atmaya başladım.

Yaptığım pluginler genelde Zombie Plague / Zombie Escape modlarına yönelik — banka sistemi, pet sistemi, ışık ayarları gibi şeyler. Türkçe, İngilizce ve Korece dil desteği eklemeye özen gösteriyorum.

---

### 🌍 About Me

I've been into CS 1.6 for many years. Spent a long time playing on servers, then slowly got into plugin development. I learned Pawn from someone I'd call a mentor — still learning to this day. Lately I've been picking up other programming languages as well.

Most of my plugins are built for Zombie Plague / Zombie Escape servers — banking systems, pet systems, custom settings. I put effort into multi-language support (TR / EN / KO).
